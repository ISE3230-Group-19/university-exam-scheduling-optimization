# university-exam-scheduling-optimization

Universities like Ohio State face an operational challenge when scheduling exams across campus
each semester. Assigning exams to specific lecture halls, classrooms, and time blocks manually
often results in overcrowded rooms and scheduling conflicts for students such as overlapping
exam times or multiple difficult exams on a single day. In a practical university setting, we
would want an efficient schedule that directly enhances student performance in their academics
that optimizes campus facility management. This project addresses this decision problem by
using a Mixed Integer Linear Program (MILP) to automate these room assignments for exams.

The goal is to create schedules that minimize student conflicts while making sure lecture halls
and classrooms have enough seats, are not booked by multiple exams, and students do not have
overlapping exams.
